# Численное моделирование горения метано-кислородной смеси

Учебно-исследовательский проект по моделированию горения метана на основе двухстадийной химической реакции:

1. `CH4 + 1.5 O2 -> CO + 2 H2O`
2. `CO + 0.5 O2 -> CO2`

Модель описывает изменение температуры и концентраций `CH4`, `O2`, `CO`, `CO2` и `H2O`. Для разгона используется метод Рунге–Кутты четвёртого порядка, далее применяется реализованная в прототипе схема метода Гира.

## Структура проекта

```text
methane-oxygen-combustion/
├── src/
│   └── simulation.py       # модель, численный метод и построение графиков
├── results/                # результаты расчёта, создаются при запуске
├── requirements.txt        # зависимости Python
├── .gitignore
└── README.md
```

## Требования

- Python 3.10 или новее
- NumPy
- Matplotlib

## Установка и запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python src/simulation.py
```

В Windows команда активации окружения выглядит так:

```powershell
.venv\Scripts\activate
```

По умолчанию расчёт выполняется при начальной температуре `780 K` на интервале `0–0.02 с`. Результаты сохраняются в папку `results`:

- `temperature.png` — изменение температуры;
- `concentrations.png` — изменение концентраций компонентов;
- `simulation.csv` — численные значения по шагам расчёта.

Другую начальную температуру можно передать через аргумент командной строки:

```bash
python src/simulation.py --temperature 850
```

Доступные параметры можно посмотреть командой:

```bash
python src/simulation.py --help
```

## Статус

Текущая версия является исследовательским прототипом. Перед использованием результатов в окончательных выводах ВКР требуется провести проверку устойчивости по шагу интегрирования и сопоставить расчёты с опубликованными или экспериментальными данными.
